## Project Overview
This project investigates the underlying factors influencing student academic performance (Final Grade G3) using a dataset of 1,044 combined records from Mathematics and Portuguese courses. 

Rather than assuming direct cause-and-effect, this Exploratory Data Analysis (EDA) identifies hidden behavioral patterns across lifestyle choices, study habits, family background, and alcohol consumption to understand the broader context of academic success. 

## Tech Stack & Tools
* **Data Manipulation & Analysis:** Python, Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Interactive Web Dashboard:** HTML5, CSS3, JavaScript, Chart.js
* **Presentation & Reporting:** Canva / PowerPoint

## Key Analytical Insights
1. **The Social Pipeline:** There is a strong correlation between socializing frequency, weekend alcohol consumption, and increased school absences. Heavy weekend drinkers accumulate significantly more missed days of school.
2. **Academic History Matters Most:** Previous class failures proved to be the strongest negative numerical indicator of final grades (r = -0.38), heavily outweighing lifestyle factors.
3. **The Context of Success:** Educational aspirations and parental education levels showed strong positive relationships with academic outcomes, proving that performance is deeply embedded in a student's wider family environment.
4. **Association vs. Causation:** While heavy weekend drinking correlates with a noticeable decrease in grades, substantial overlap between groups indicates that alcohol alone does not explain student performance.
